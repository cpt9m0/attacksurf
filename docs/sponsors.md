# Sponsoring attacksurf

attacksurf is free and open source (AGPL-3.0). Sponsorship keeps it that way.

## Where the money goes

| Cost | Why |
|---|---|
| Hosting | a free public instance and live demo (VPS, backups, domain) |
| LLM tokens | AI triage for free-tier users who don't bring their own key |
| Data sources | threat-intel / DNS data APIs with paid tiers |
| Maintenance | reviewing contributions, security fixes, new scanners |

We plan to publish a simple summary of income and spending with each release.

## How to sponsor

- **[GitHub Sponsors](https://github.com/sponsors/cpt9m0)**: monthly or one-time; 0% fees
- **[Ko-fi](https://ko-fi.com/cpt9m0)**: quick one-off support

## Tiers (GitHub Sponsors)

| Tier | Perks |
|---|---|
| ☕ Supporter | our thanks + sponsor badge |
| 🛡️ Backer | name in the README sponsors list |
| 🏢 Company | logo in the README and docs, priority on feature requests |
| 🏰 Partner | large logo, roadmap input, help with self-hosted deployments |

Tiers and amounts are configured on the GitHub Sponsors profile.
